HBNI · RE501 · Neutron transport

Follow one neutron. Then a billion.

A neutron is born in a fission, flies a random distance, hits a nucleus, and then scatters, gets absorbed, or splits it to make more neutrons. This course first builds the probability you need to describe that, then uses it to derive transport theory.
